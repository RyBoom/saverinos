# Savarino's homepage prototype

A single-file, mobile-first homepage prototype for Savarino's Bakery, Deli & Market, 314 W 11th St, Columbia, TN. Built as a cold pitch to the owner.

- **The page:** `site/index.html`. One file, inline CSS and JS, Google Fonts (League Gothic, Besley). Open it in a browser or deploy the `site/` folder to any static host (Cloudflare Pages: set the output directory to `site`).
- **Product truth:** `PRODUCT.md` (verified facts only).
- **Design system:** `DESIGN.md` and `.impeccable/design.json`.

Keep `PRODUCT.md`, `DESIGN.md` and `.impeccable/` out of anything you deploy. They are working notes, not site files.

## Waiting on the owner

Everything drawn with a dotted line on the page is a placeholder:

- Hours (listings disagree online). Once confirmed, fill the `HOURS` object near the bottom of `site/index.html` and the hero's "Today" line starts showing open or closed status in Central time.
- Pre-order lead time for family pans and cakes
- Wholesale delivery area and days, wholesale email
- TikTok handle
- Voice lines for the Sicilian, Sausage & Pepper and Chicken Parm (only the Palermo's story is verified)
- Every photo. Each placeholder names the exact shot needed.
- Google Maps embed in the Visit section
