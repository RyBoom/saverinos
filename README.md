# Savarino's Market: concept site

A two page, mobile first concept for Savarino's Market, a Sicilian family bakery, deli and market at 314 West 11th Street, Columbia, TN. Built as a pitch for the owner, Carmelo Savarino.

- **Pages:** `site/index.html` (homepage) and `site/menu.html` (the menu).
- **Assets:** `site/assets/` holds the stylesheet, one small script, two self hosted fonts (Abril Fatface, Montserrat), the cropped color logo, the engraved cannoli pieces lifted from the logo, and the maiolica ornaments traced from it.
- **Stack:** plain HTML, CSS and JavaScript, no dependencies, nothing to install to view it. The two pages are generated by `tools/build_pages.py` (Python 3, standard library only) so the header, footer and forms stay identical. To change copy or markup, edit the script, run `python3 tools/build_pages.py`, and commit the script and both pages. CSS and JavaScript are edited directly in `site/assets/`.
- **Run it:** `cd site && python3 -m http.server 8765`, then open `http://localhost:8765`. Serve it over HTTP rather than opening the files directly, so the fonts load.
- **Deploy:** any static host. For Cloudflare, `wrangler.jsonc` serves the `site` folder as Workers static assets, with the free `workers.dev` and preview addresses switched off. `site/_headers` and `site/robots.txt` keep the concept out of search and AI crawlers. The private address it is served from is deliberately not recorded in this repo.
- **Preview a time of day:** add `?now=2026-10-10T16:30` to a page address. The open or closed line reads that as Central time.
